1. 모바일 가로 HUD · 실제 크기

화면은 확대하지 않은 실제 CSS 픽셀입니다. 844×390은 6.1인치급 폰, 640×360은 소형 폰 가로 화면입니다. 지도를 가리는 전체 폭 띠 대신 네 모서리의 정보판과 왼쪽 가장자리 도구 레일을 씁니다.

A. 관리 · 탐색 (844×390)
· 왼쪽 위: 자금·손익과 만족도 정보판. 누르면 재정·만족도 화면을 엽니다.
· 오른쪽 위: 시간 | 일시정지 | 배속(누를 때마다 ×2→×5→×10→×100) | 뉴스 | 메뉴. 드롭다운은 쓰지 않습니다.
· 왼쪽 가장자리: 모드 전환과 현재 모드 도구 레일(행 높이 44). 왼손 엄지로 닿습니다.
· 왼쪽 아래: 실행 취소·다시 실행. 오른쪽 아래: 선택 객체 inspector와 주 행동(높이 48).

B. 공사 · 노선 건설 검토 (844×390)
· 정밀 작업 중이라 레일을 64px로 줄입니다. 되돌리기·취소는 왼쪽 아래, 건설 확정과 비용은 오른쪽 아래 엄지 위치에 48px 높이로 둡니다.
· 거리·비용 tooltip은 손가락에 가리지 않도록 접촉점 옆에 띄웁니다.

C. 관리 · 노선 inspector 확장 (844×390)
· 여러 수치를 볼 때는 inspector를 위로 확장합니다. 이때 레이어 버튼은 inspector 뒤로 숨고, 시간 정보판은 그대로 보입니다.

D. 소형 폰 + 노치 (640×360)
· 노치 쪽 safe area만큼 왼쪽 HUD를 안으로 들입니다. 정보판의 보조 문구(자금, 안정)를 접고 수치와 표식만 남깁니다.
· 모드 배너는 정보판 아래로 내리고, 레일은 64px compact를 씁니다.
