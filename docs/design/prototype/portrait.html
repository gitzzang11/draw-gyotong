세로 화면 시안 — 폰을 세워도 같은 게임, 엄지는 아래에

폰 세로(390×844, 작은 폰 360×780까지)에서의 배치입니다. 가로 화면은 지금 그대로 둡니다. 화면이 세로가 되면 왼쪽 세로 레일이 화면 아래 가로 레일로, 오른쪽 아래 정보창이 레일 바로 위 전체 폭 안내판으로 옮겨집니다. 한 손으로 잡았을 때 엄지가 닿는 곳이 화면 아래쪽이기 때문입니다.

  • 위: 재정 정보판(자금 아래 줄에 순익·만족도를 겹쳐 폭을 줄임)과 시간 정보판(날짜·시각 · ▶ · 배속 · 뉴스 · 메뉴). 그 아래 가운데 모드 배너, 오른쪽 레이어 버튼. 읽기 위주라 손이 덜 닿아도 됩니다.
  • 아래: 도구 레일(왼쪽 반전 칸이 현재 모드, 누르면 위로 모드 목록이 펼쳐짐 · 도구는 화면 폭에 들어가는 만큼, 나머지는 더보기). 그 위 왼쪽에 실행 취소·다시 실행.
  • 정보창·검토: 레일 위 전체 폭. 처음엔 화면 높이의 40% 안(이름·핵심 수치·주 행동). 위쪽 손잡이 줄을 누르거나 끌면 정보판 아래까지 펼쳐짐. 주 행동·확정은 안내판 맨 아래 오른쪽(엄지). 열릴 때 고른 대상이 남은 지도 가운데로 오도록 지도를 옮깁니다. 정보창이 열려도 도구 레일은 그대로 보입니다.
  • 전체 화면(운영 현황·통계·뉴스·노선도·시작 화면): 두 열을 한 열로 쌓고, 목록 → 상세는 같은 화면에서 아래로 이어집니다.
  • 대화상자: 좌우 12px만 남긴 전체 폭, 확정 버튼은 아래.
