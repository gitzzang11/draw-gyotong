# WorldPop 2020 South Korea population grid

`src/data/worldPopKorea2020.ts` contains a city-window extract from WorldPop's 2020 South Korea 100 m total-population grid (DOI: 10.5258/SOTON/WP00645).

The source provides estimated people per approximately 100 m WGS84 grid cell and is licensed under CC BY 4.0. It is used here as an input to the game's potential-demand distribution, not as a live population count.

Source: https://worldpop.arcgis.com/arcgis/rest/services/WorldPop_Total_Population_100m/ImageServer
