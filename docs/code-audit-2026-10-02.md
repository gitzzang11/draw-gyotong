## 01. 역명 툴팁의 HTML/스크립트 실행

- 영향: 조작된 외부 역명이나 공유 계획의 역명이 실제 역으로 표시될 때 게임 오리진 안에서 JavaScript를 실행할 수 있다. 게임 저장소 열람·변조 위험이 있다. 네이티브 코드 실행이나 실제 세이브 탈취는 시험하지 않았다.
- 보완 방향: 이름은 `textContent`를 넣은 DOM 요소로 전달하거나 공통 이스케이프 함수를 적용한다. 모든 툴팁 경로를 같은 규칙으로 처리한다. 입력 길이 제한과 CSP는 추가 방어이며 출력 인코딩을 대체하지 않는다.

## 08. 조회 중 계획을 건설하면 자동 이름 결과가 사라짐

- 근거: [refineAutomaticStationName:5808](<C:/src/draw gyotong/src/main.ts:5808>), [계획 역 전환:8120](<C:/src/draw gyotong/src/main.ts:8120>).
- 계획 역의 이름 조회는 완료 시 원래 계획 역 ID를 다시 찾는다. 건설 전환은 다른 실제 역 ID를 생성하고 현재 이름을 복사한다. 완료된 계획이 정리되면 원래 대상은 없어지며 실제 역으로 결과를 넘기는 처리가 없다.
- 재현: 계획 역 이름 조회를 대기시킨 뒤 실제 역을 생성하고 계획을 제거했다. 조회 결과 `공항`이 도착했지만 실제 역 이름은 `임시 이름`으로 남았다.
- 영향: 역명 데이터가 정상적으로 도착해도 빠르게 건설 전환한 역에는 자동 이름이 적용되지 않는다. 수동 이름 보호를 위해 이름 일치 검사는 계속 필요하다.
- 보완 방향: 계획 역→실제 역의 ID 관계로 대기 중 결과를 전달하거나 전환된 실제 역에 조회를 다시 시작한다. 직접 이름을 바꾼 역은 덮어쓰지 않는다.
