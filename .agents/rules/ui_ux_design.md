# Rule: UI/UX 디자인 시 실제 서비스/앱 참고 (Reference Real-World Apps for UI/UX Design)

## Description
웹 애플리케이션 및 UI/UX 개발 시, 임의의 일반적인 디자인 기법(과도한 애니메이션, 유리 질감 등)을 무조건 적용하지 않고, 시중에 실제 서비스 중인 대표적인 앱/웹의 UI/UX 디자인 및 레이아웃을 참고하여 익숙하고 검증된 완성도 높은 디자인을 구현합니다.

## Execution Rules
1. **시중 앱 디자인 벤치마킹**: UI/UX 설계 및 개발 시 사용자에게 익숙한 기존 서비스(대중적인 상용 앱/웹)의 레이아웃, 컴포넌트 구조, UX 패턴을 참고합니다.
2. **실용성과 직관성 우선**: 시중 앱에서 검증된 레이아웃과 디자인 패턴을 반영하여 사용자가 직관적으로 사용할 수 있도록 구현합니다.
